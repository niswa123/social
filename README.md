# 📊 Медиа-карта Крыма: Мониторинг новостных пабликов

Добро пожаловать в проект **Медиа-карта Крыма**! Это интерактивный дашборд для отслеживания статистики популярных новостных каналов, городских сообществ и ЧП-групп Крыма в Telegram, ВКонтакте, Instagram и X (Twitter).

Проект разработан так, чтобы им мог пользоваться абсолютно любой человек — даже тот, кто впервые открыл ноутбук. Ниже находятся две простые инструкции: как сразу открыть готовую карту и как обновить данные до самых свежих.

---

## 🚀 Способ 1: Быстрый запуск (За 5 секунд без настроек)
*Для этого способа вам не нужно ничего устанавливать или настраивать. Всё уже работает.*

1. **Найдите папку проекта** на вашем компьютере.
2. Найдите файл с именем **`index.html`** (он выглядит как значок вашего браузера: Chrome, Safari или Яндекс.Браузер).
3. **Дважды щелкните** по файлу `index.html` левой кнопкой мыши.
4. Откроется вкладка в браузере с красивым, полностью рабочим дашбордом! Вы можете искать паблики, фильтровать их по городам и сортировать по популярности.

---

## ⚙️ Способ 2: Обновление данных (Для продвинутых)
*Если вы хотите запустить «робота» (скрипт-скрапер), который зайдет в интернет, соберет самую свежую статистику подписчиков, лайков и просмотров с каналов и обновит карту.*

Для этого нам понадобится программа **Python** (Питон) и командная строка. Не пугайтесь, это очень просто!

### Шаг 1. Откройте Терминал (командную строку)
* **На Mac (Apple):** Нажмите клавиши `Command (⌘) + Пробел`, введите слово `Терминал` в появившемся поиске и нажмите `Enter`.
* **На Windows:** Нажмите клавишу `Windows` (с флажком) на клавиатуре, введите `cmd` или `Командная строка` и нажмите `Enter`.

### Шаг 2. Перейдите в папку проекта в Терминале
1. Введите в терминал команду перехода `cd ` (обязательно с пробелом после cd):
   ```bash
   cd 
   ```
2. **Секретный трюк:** Просто перетащите папку `vk,insta` мышкой из проводника/Finder прямо в окно Терминала! Путь к папке подставится автоматически.
3. Нажмите `Enter`. Теперь ваш терминал «находится» внутри папки с проектом.

### Шаг 3. Установите необходимые дополнения (библиотеки)
Нам нужно установить две библиотеки, которые помогают роботу скачивать страницы из интернета. Скопируйте эту строчку, вставьте её в терминал и нажмите `Enter`:

```bash
pip3 install requests beautifulsoup4
```
*(Если на экране побежали строчки и в конце написано `Successfully installed...` — всё прошло отлично!)*

### Шаг 4. Запустите сбор данных
Теперь запустим самого робота. Введите команду ниже и нажмите `Enter`:

```bash
python3 scraper.py
```

**Что произойдет:**
* Вы увидите текстовые сообщения на экране: робот начнет по очереди обходить Telegram-каналы и группы ВКонтакте.
* Это займет около 1–2 минут. Робот специально делает небольшие паузы, чтобы социальные сети его не заблокировали.
* В самом конце появится радостная надпись: **`SUCCESS: Saved parsed database to data.js!`**

### Шаг 5. Посмотрите результат!
Теперь просто вернитесь в браузер, где открыт файл `index.html`, и обновите страницу (нажмите круглую стрелочку или клавиши `Cmd + R` на Mac / `F5` на Windows). Данные обновятся на самые свежие!

## 💡 Возможности дашборда (Как им пользоваться)

* **🔍 Умный поиск:** Начните вводить название паблика или название города (например, *Ялта* или *ЧП*) в поисковой строке вверху. Список отфильтруется на лету.
* **📱 Фильтр по платформе:** Вы можете смотреть только каналы в Telegram, только группы ВКонтакте или всё вместе.
* **🌆 Фильтр по городам:** Выберите конкретный город (Симферополь, Севастополь, Керчь, Евпатория, Феодосия, Ялта), чтобы увидеть местную прессу.
* **📈 Сортировка:** Нажимайте кнопки сортировки, чтобы мгновенно выстроить каналы по:
  * Количеству подписчиков (аудитории);
  * Среднему числу просмотров постов;
  * Среднему числу лайков;
  * Коэффициенту вовлеченности (ER) — насколько аудитория активна.
* **📋 Подробный анализ:** Нажмите на любую карточку паблика, чтобы развернуть детальную статистику и прочитать подробный разбор показателей вовлеченности.

## 📂 Из чего состоит проект (Для любопытных)

* 📄 **`index.html`** — главная страница. Это каркас нашего дашборда (кнопки, заголовки, разметка).
* 🎨 **`dashboard.css`** — файл стилей. Он отвечает за внешний вид: темную тему, красивые градиенты, плавные анимации и шрифты.
* ⚙️ **`dashboard.js`** — «мозг» интерфейса. Он фильтрует, сортирует и отображает данные на экране, а также рисует графики.
* 📊 **`data.js`** — база данных. Сюда робот-скрапер записывает собранную информацию.
* 🤖 **`scraper.py`** — робот-скрапер, написанный на языке Python. Он собирает цифры из соцсетей.
* ⚙️ **`targets.json`** — список ссылок. Здесь записано, какие именно паблики и каналы робот должен проверять.

## 🛠️ Решение частых проблем (Если что-то пошло не так)

### ❓ Пишет «Команда `python3` не найдена» или `command not found`
> [!NOTE]
> Это означает, что на вашем компьютере еще не установлен язык программирования Python.
> 
> **Решение:** 
> 1. Перейдите на официальный сайт [python.org](https://www.python.org/downloads/).
> 2. Нажмите желтую кнопку **Download Python** (Скачать Python).
> 3. Откройте скачанный файл и установите его как обычную программу. 
> 4. **Важно для Windows:** При установке обязательно поставьте галочку напротив пункта **"Add Python to PATH"** (Добавить Python в переменную окружения PATH).
> 5. Перезапустите Терминал и попробуйте снова.

### ❓ Ошибка при установке библиотек (`pip3 install...` выдает ошибку)
> [!TIP]
> Иногда системе не хватает прав для установки библиотек во внутренние папки.
> 
> **Решение:** Попробуйте установить их только для своего пользователя, добавив `--user` в конце команды:
> ```bash
> pip3 install requests beautifulsoup4 --user
> ```

### ❓ Данные в браузере не обновились после работы скрапера
> [!IMPORTANT]
> Ваш браузер мог запомнить старую версию файла, чтобы открывать страницу быстрее (это называется кэш).
> 
> **Решение:** Очистите кэш страницы. Для этого зажмите клавишу `Shift` и, не отпуская её, нажмите кнопку обновления страницы в браузере. Или нажмите `Cmd + Shift + R` (на Mac) / `Ctrl + F5` (на Windows).
